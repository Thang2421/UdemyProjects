I. ** forkify--Cookingrecipes-API **

Before running the project, make sure you have Node.js and npm installed. Then install dependencies from package.json and run:

npm start

This application allows users to search for cooking recipes using a query. The app fetches and displays a list of relevant recipes. Users can:

- View recipe details (name, image, cooking time, servings, ingredients, etc.)
- Adjust servings, which dynamically updates ingredient quantities
- Navigate through results using pagination
- Click “Directions” to view full cooking instructions

II. ** Mapty-Geolocation **

Before running the project, please make sure the user wifi router allows to get your current locaiton (GPS Coordinates, latitude and longitude ) and allow the browser to get your live-location.

This app allows users to track workouts on a map using their live location (GPS coordinates).

Features:

- Select a location on the map
- Log workout data (type, distance, duration, elevation/cadence)
- View workout history in a sidebar
- Click a workout to highlight it on the map

All data is stored in localStorage, so it persists after page reload.

V. ** Game-GuessMyNumber **
This is a simple number guessing game written in JavaScript. The program generates a random secret number from 1–20, and the player enters guesses while receiving hints like “too high” or “too low.” Each wrong guess reduces the score, and a correct guess wins the game and updates the high score. The game also includes a reset button to play again.

VI. ** Game-TwoPlayersDice **

A two-player dice game where players take turns rolling.

- Rolling adds to the current score
- Rolling a 1 resets the turn score and switches player
- Players can “hold” to save points
- First player to reach 100 points wins
